2. 主要機能
===============================================================================

[2.1] Pure-Pursuit制御アルゴリズム
- 曲率ベース: k = 2*sin(α)/Ld
- 角速度: ω = v * k * steer_gain
- 速度調整: v = v_base / (1 + k_gain * |k|)

[2.2] フォールバック機能
優先度: 中央線 → 最後の有効中央線 → 左線 → 右線 → 停止
- 中央線が見失われても最後の有効な点群を保持
- 左右線へ自動切替
- 中央線復帰時は自動的に戻る

[2.3] 安全停止機能
- Ctrl+C終了時に自動的に速度0のコマンド送信
- __del__()とfinally句で二重に停止処理

[5.2] 安全停止処理
---
def __del__(self):
    """ノード破棄時に停止コマンド送信"""
    self.send_stop_command()

def send_stop_command(self):
    """速度0のTwistをパブリッシュ"""
    try:
        twist = Twist()
        twist.linear.x = 0.0
        twist.angular.z = 0.0
        self.pub.publish(twist)
        self.get_logger().info('Stop command sent')
    except Exception:
        pass
---

[5.3] メインループ (main)
---
def main(args=None):
    rclpy.init(args=args)
    node = LaneTracer()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass  # Ctrl+C を捕捉
    finally:
        node.send_stop_command()  # 停止コマンド送信
        node.destroy_node()
        rclpy.shutdown()

[5.4] 中央線コールバック (lane_callback)
---
def lane_callback(self, msg: PointCloud2):
    points = []  # PointCloud2から(x,y)抽出
    for p in point_cloud2.read_points(msg, field_names=("x", "y"), skip_nans=True):
        x, y = p[0], p[1]
        if x >= 0.0:  # 前方のみ
            points.append((float(x), float(y)))
    
    if not points:
        self.process_with_fallback()  # フォールバック処理
        return
    
    self.last_center_points = points  # 有効点を保存
    self.process_lane_points(points)
---

[5.5] Pure-Pursuit制御 (process_lane_points)
---
def process_lane_points(self, points: List[tuple]):
    target = self.find_target_point(points, self.lookahead)
    alpha = math.atan2(target[1], target[0])
    
    # 曲率計算
    if self.lookahead > 0.0:
        curvature = 2.0 * math.sin(alpha) / self.lookahead
    else:
        curvature = 0.0
    
    # 角速度計算
    angular_z = self.base_speed * curvature
    angular_z = max(-self.max_angular, min(self.max_angular, self.steer_gain * angular_z))
    
    # 速度調整（曲率に応じて減速）
    speed = self.base_speed / (1.0 + self.k_gain * abs(curvature))
    if speed < 0.05:
        speed = 0.0
    
    # Twist発行
    twist = Twist()
    twist.linear.x = float(speed)
    twist.angular.z = float(angular_z)
    self.pub.publish(twist)
---

[5.6] フォールバック処理 (process_with_fallback)
---
def process_with_fallback(self):
    """優先度: 最後の中央線 > 左線 > 右線 > 停止"""
    if self.last_center_points:
        self.process_lane_points(self.last_center_points)
    elif self.last_left_points:
        self.process_lane_points(self.last_left_points)
    elif self.last_right_points:
        self.process_lane_points(self.last_right_points)
    else:
        twist = Twist()
        twist.linear.x = 0.0
        twist.angular.z = 0.0
        self.pub.publish(twist)
---
